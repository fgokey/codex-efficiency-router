# Code of Conduct

## Our pledge

We want participation in this project to be respectful, constructive, and technically useful for everyone.

## Expected behavior

- Discuss ideas and evidence, not people.
- State uncertainty and limitations clearly.
- Keep benchmark and performance claims reproducible.
- Avoid posting secrets, private repository content, or proprietary logs.
- Accept maintainer decisions when they are explained by project scope, safety, or evidence quality.

## Unacceptable behavior

Harassment, threats, discriminatory conduct, deliberate disclosure of private information, spam, and knowingly fabricated benchmark results are not acceptable.

## Enforcement

Report conduct concerns privately using the security/contact guidance in `SECURITY.md`. Maintainers may edit, hide, lock, or remove content and restrict participation when needed.

This lightweight code of conduct is intended for this repository and may be replaced by a standard community covenant in a future release.
