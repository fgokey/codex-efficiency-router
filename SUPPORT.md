# Support

Use GitHub Issues for reproducible bugs, compatibility reports, routing regressions, and feature requests.

Before opening an issue:

1. Run `python scripts/doctor.py`.
2. Run `python -m unittest discover -s tests -v`.
3. Record your Codex version, OS, available model catalog, and whether the installation is user- or repository-scoped.
4. Remove tokens, secrets, private source code, internal URLs, and proprietary logs.

For security-sensitive reports, follow `SECURITY.md` instead of opening a public issue.
