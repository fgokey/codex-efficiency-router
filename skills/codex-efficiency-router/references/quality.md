# Evidence and completion

Before final, reconcile the original user objective, accepted scope, every remaining required item and current authority. CONTINUE useful authorized diagnosis/delegation/implementation; child PASS or green local checks are not parent completion. COMPLETE requires current evidence for every requirement. BLOCKED names the exact external missing resource, evidence, affected scope and external action; finish unaffected work. STOP on explicit pause/cancel, scope change or actual system budget ceiling. Answer mid-task status briefly and continue; end standalone answers. No unrequested monitoring or risky measurements.

Reuse unchanged loaded rules; fully read necessary new/changed rules. Verify physical paths/links. Locate once; batch independent required ranges. Before declaring evidence missing, inspect packet keys and relevant pointers. Released writers: authorized bounded native reads; Astra/readonly/unknown: guarded reads. Store read_thread results; select via Reader --help (>=4096 tokens; caps truncate). Batch UTF-8, JSON, CRLF and framing within one <=4KiB budget. Reader: verified Python `-I -B`, UTF-8 stdin. Check exit before parsing; retain successes, errors, cursors and test exits/counts/failures. Read required ranges completely; continue missing pages rather than rereading files. Never slice full-file output, concatenate pages to evade limits or infer completion from truncation.

Review available work before waiting. Batch independent reads and merged worker waits. Use native event waits; no final with required work open. Inspect detail on actionable change, failure or completion; after two unchanged snapshots back off. One saved-offset diagnostic delta; no repeated tails/nudges without new evidence. `COORDINATION_JS` is an adapter, not proof of work. Code Mode: first-line `@exec` yield covers WHOLE wait; resume with maximum supported yield; never start another wait cell. Quiet: prefer Reader `COORDINATION_QUIET_JS` with advertised 120s yield (two 50s waits); else one native wait. No unchanged status/admission/completion polling.

Check platform/macros, consumers and lifecycle effects. Loss/eviction/coalescing must preserve effects or prove safe discard/replay/rebuild. Findings need source evidence or a requirement violation; distinguish hypotheses and preexisting hazards. Tests use production behavior or labelled models; green model/static scores are not proof of end-to-end correctness. Never weaken assertions.

Attempts persist per task/unit/failure across owners, models and compaction. Patch mismatch: inspect context/encoding/EOL, repair once. Exhaustion stops blind edits, not Astra diagnosis. Required checks on final stable state; repeat affected/failed only. Unrun evidence is UNKNOWN; required gaps remain PARTIAL/BLOCKED. Parent: open the actual source/diff/result; assess caller/test applicability/blockers. Reject child reports and completion_check declarations alone; reuse unchanged evidence. `completion_check` only when provided by the host: begin before append; check changed/final work. Keep complete id/task_revision inventory; one work entry/id. Repage new revision only; event-only changes reuse ids. After tool results: fresh inspect then check alone; work/input invalidates it. Child status adds no work. Retained independent: `turn_scope:independent_answer`; no retained work: no check. Count parent/child work; cached input is a subset; absent prices/usage: UNKNOWN.
