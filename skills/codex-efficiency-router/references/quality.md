# Evidence and recovery

Contract: requirement | current check/review | state | PASS/FAIL/UNKNOWN. Child PASS is unit evidence. Parent PASS requires every delivered diff and actual validation reviewed, corrections rechecked, no blocking finding, and final integration acceptance. Optional risks may coexist with PASS; required gaps may not.

Checkpoint: contract/state, valid work, workers, failures/pairs and absolute ceiling. Update on transitions; no secrets/overwrite. Patch mismatch first checks expected/current context, encoding and line endings; after one justified repair, a second same-signature failure stops blind retry. Renaming never renews retries. Offline helpers prove neither enforcement nor quality.

Compare existing parent/child logs at task end: cost, time, rework, acceptance. Missing usage/prices stay UNKNOWN; no extra calls/polls.
