# Evidence and completion

Before final, reconcile the original user objective, accepted scope, every remaining required item and current authority. CONTINUE while useful authorized diagnosis, delegation or implementation remains; child PASS or green local checks are not parent completion. COMPLETE requires current evidence for every requirement. BLOCKED requires the exact external missing resource, evidence, affected scope and required external action; finish unaffected work. STOP on explicit pause/cancel, scope change or actual system budget ceiling. Answer mid-task status briefly and continue; standalone questions end after answering. Never start unrequested monitoring or risky measurements.

Reuse unchanged loaded rules; fully read necessary new/changed rules. Verify physical paths/links. Locate once; batch independent required ranges. Released writers: authorized bounded native reads; Astra/readonly/unknown: guarded reads. Store read_thread results; select via Reader --help (>=4096 tokens; caps truncate). Batch UTF-8; one aggregate budget including JSON, CRLF and framing (<=4KiB). Reader: verified Python `-I -B`, UTF-8 stdin. Check exit before parsing; retain successful results, errors and each cursor; test exits/counts/failures. Read required ranges completely; continue missing pages rather than rereading files. Never slice full-file output, concatenate pages to evade limits or infer completion from truncation.

Review available work before waiting. Batch independent reads and merged worker waits. Use native event waits; no final with required work open. Inspect detail only on actionable change, failure or completion; after two unchanged snapshots back off. One saved-offset diagnostic delta is enough; do not repeat tails or nudges without new evidence. Optional `COORDINATION_JS` is an adapter, not proof of work. Code Mode: first-line `@exec` yield covers WHOLE wait; resume cells with supported yield; never start another wait cell. Reader `COORDINATION_QUIET_JS`: at most two 50s waits under advertised 120s yield; else one native wait. No status/admission/completion polling while unchanged.

Check platform/macros, consumers and lifecycle effects. Loss/eviction/coalescing must preserve effects or prove safe discard/replay/rebuild. Findings need source evidence or a requirement violation; distinguish hypotheses and preexisting hazards. Tests use production behavior or labelled models; green model/static scores are not proof of end-to-end correctness. Never weaken assertions.

Required checks on final stable state; repeat affected/failed only. Unrun evidence is UNKNOWN; required gaps remain PARTIAL/BLOCKED. Reject child reports and completion_check declarations alone; reuse unchanged evidence. `completion_check` only when provided by the host: begin before append; check changed/final work. Keep complete id/task_revision inventory; one work entry/id. Repage new revision. After tool results: fresh inspect then check alone; work/input invalidates it. Child status adds no work.
