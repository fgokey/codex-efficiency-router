# Evidence/recovery

## Completion

Before an active engineering parent final, reconcile the original user objective, accepted scope, every remaining required item and current authority.

- CONTINUE while useful authorized diagnosis, delegation or implementation remains. Child PASS/PARTIAL or local checks/reviews never complete the parent. Missing measurements or an unresolved design decision alone never establish completion/blockage. Do not require the user to type continue.
- COMPLETE only when every required item is satisfied by current evidence.
- BLOCKED only for an actual external barrier: name exact missing access/input/resource, evidence, affected scope and required user/external action; finish unaffected authorized work.
- STOP on explicit stop/pause/cancel, accepted scope change or actual tool/system budget ceiling; report remaining work.
- STATUS/Q&A ends only a standalone question task. During active work answer briefly then continue the original objective unless stopped/changed.

Continue within existing authority/scope; no automatic monitoring, risky measurement/deploy, new authority, infinite retry or extra model probes.

Files/rules: `page`; unknown: `locate --query Q`; current located lines: `excerpt --start N --lines N` (count 1..200). Fix limits/page/locate errors.

Checks: one Reader `batch --requests JSON_ARRAY --max-bytes N --framing-bytes N`. Check exit; one results JSON; keep each cursor. JSON+CRLF+framing <=4KiB or narrow; no early member output. Resume gaps; disclose omissions. Other: capture/select/serialize/count before emit. Commentary/queries/waits/prompt rewrites do not reset backoff. Two unchanged snapshots: one saved-offset delta then back off; no repeat tails/polls/nudges until change. No doc/hook preload or child router copy. Reconcile requested/observed/unknown effects before replay. Never invent identity/savings/enforcement/cleanup.

Check semantic invariants, platform/macros, consumers, validation. Loss/eviction/coalescing: preserve effects or supported discard/replay/rebuild in affected states; else PARTIAL/BLOCKED.

Exhaustion stops blind edits, not diagnosis. Patch mismatch: inspect context/encoding/line endings; repair once, stop repeats. Retries persist per task/unit/signature across ALL owners/models/efforts/compaction; exhaustion needs diagnosis/justified absolute ceiling.

New tests != independent proof. Do not weaken assertions. Unrun is UNKNOWN, not PASS; required gaps: PARTIAL/BLOCKED.

Callback/gray/static score cannot prove event loss safe. Keep preexisting hazards open; unchanged baseline != diff.
