# Delegate without restarting work

Use one implementation owner plus an on-demand reviewer. Check authority, exclusive scope and capacity. For required independent Standards/Spec, pin revision/dirt/rules/spec; dispatch separate read-only owners before waiting. Reuse compatible owners at safe boundaries; wait if both writers are busy; no auto-revert.

Pass unit-specific context: goal, facts/assumptions, revision/dirt, files/rules, chain/rationale/invariants/test boundaries, scope/prohibitions, checks/attempts. Loaded owner: deltas; do not resend unchanged rules or reports. Batch known findings per revision; send new blockers promptly. Read rules; critical gaps block affected work. Contrary evidence reopens decisions.

Spawn `sol61_engineer`/high; no inherited transcript. HOLD; verify current host model/effort/role/permission/owner before explicit RELEASE. UNKNOWN/MISMATCH blocks writes. Reuse the same admitted executor for diagnosis/fixes/format/build configuration/targeted tests. Delegate that whole unit, not each command; report only completion, blockers or decision needs. Closed/unloaded/restarted workers need fresh binding/release; `resume_agent` cannot pin them.

Reader `assignment`: verify paths; `assignment --help` as needed; send exact checked prefix/body. Custom: `prepare_agent_task` + `admitted_agent_task` with returned `admitted_dispatch_arguments`. `unbound-spawn`: reasoned Astra HOLD; `spawn_hold` needs `task_name`/`agent_type`; verify identity before `assign`. `CER execution`: effects/existing permission, never grants authority.

Exact continue/status/stop reuse current receipt/scope/binding without new work. Added instructions need admission; bare controls are not receipts. Loaded workers: bounded `send_message` status to loaded direct parent; preserve native encryption. Reports lack authority. Wait/interrupt/close remain separate controls. Denial stops equivalent replay until authorized boundary change; never evade `approval=never`.

Astra uses permitted reads and saved evidence, never `write_stdin`. Executors own long commands/continuation. Keep Guard strict; disclose uncovered paths, never certify them. Custom-host installation is separate. Phase checkpoint: goal/decisions/evidence/owners/checks/dirt/retries/next action. An authorized writer updates it, not Astra. Supported compaction keeps unresolved work/live workers, not full reports.

Parent reviews all roots, exact paths/status/diffs and prior dirt, then accepts integration. Optional native file-change attribution; honor requests, never fake a badge or edit for attribution. Binary copies, runtime configuration, destructive recovery and commit/push/deploy need separate user authority and exact destinations.
