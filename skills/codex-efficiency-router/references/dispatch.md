# Delegate without restarting the workflow

Default to one implementation owner plus an on-demand reviewer. Check authority, exclusive scope and capacity. Reuse a compatible owner at a safe boundary; wait when both writers are busy. Keep prior edits; no auto-revert.

Handoff goal, facts versus assumptions, revision/dirt, files and rule paths, rationale/invariants, scope, prohibitions, checks and attempts. Read required rules; critical gaps block affected work. Contrary evidence reopens decisions.

Spawn with explicit role/effort and no inherited transcript. HOLD until current host model/effort/role/permission/owner is verified; then explicitly RELEASE the unit. UNKNOWN/MISMATCH blocks writes. Keep the same admitted executor for diagnosis, fixes, formatting, build configuration and targeted tests. Delegate that whole unit, not each command; report only completion, blockers or decision needs. Closed/unloaded/restarted workers need fresh binding/release; raw `resume_agent` cannot pin them.

Registered dispatch uses Reader `assignment`. Verify paths; read `assignment --help` only when needed. Send exactly the checked prefix and body. Custom hosts use `prepare_agent_task` and `admitted_agent_task`; always pass returned `admitted_dispatch_arguments` to bind the exact recipient/configuration. `CER execution` declares effects and existing permission, never grants authority.

Exact continue/status/stop controls reuse the current receipt, scope and binding without new work. Added instructions require new admission. Bare control words are not receipts. Wait/interrupt/close remain separate controls. Policy denial stops equivalent replay until an authorized boundary change; never evade `approval=never`.

Astra uses permitted reads and saved evidence, never `write_stdin`. Executors own long commands/continuation. Strict Guard remains strict; disclose uncovered paths, never certify them. Custom-host installation is separate. At safe phase boundaries checkpoint goal, decisions, evidence paths, owners, checks, dirt, retries and next action. An authorized writer updates it, not Astra. Use supported compaction; retain unresolved items, never copy full reports or restart live workers.

Parent reviews all roots, exact paths/status/diffs and prior dirt, then accepts integration. Native parent file-change attribution is optional unless required by the user; never fake a badge or edit for attribution. Binary copies, runtime configuration, destructive recovery and commit/push/deploy need separate user authority and exact destinations.
