# v0.3.0 validation

Baseline: v0.2.1 commit `1d7a93df1a3700d1c20e0100a5889677cb6163c3`, tree `ed032b3554f768398dbb14795e633b5c2cead54f`. Local starting archive was checked against that tree.

Quality helpers, declared-signal tests, selected mutations, source budgets and corpus structure are offline evidence only. Twenty natural-language cases are prepared but not executed by CI. Actual role/model/effort identity, handoff compliance, task quality, full usage and speed remain user-run acceptance. No Codex or model API is invoked by these tests.

The workflow associated with the actual code commit is the source of truth for remote status. Results and measurements will be recorded after that workflow completes; old CI results are not transferred to new commits.
